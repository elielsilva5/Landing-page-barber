# Landing-page-barber

# 💈 Barber Shop — Landing Page Responsiva

> Projeto de uma landing page moderna para uma barbearia fictícia, desenvolvido para praticar conceitos fundamentais de desenvolvimento web front-end e resolução autônoma de problemas de código.

---

## 📌 Sobre o Projeto

Este projeto consiste na criação de uma página institucional responsiva para uma barbearia. A aplicação foi construída com foco em estruturação semântica, estilização moderna e interatividade para proporcionar uma excelente experiência ao usuário em dispositivos móveis e desktops.

Além da implementação guiada, o maior diferencial do desenvolvimento foi a **identificação e correção autônoma de *bugs* e inconsistências de código** ao longo do processo, aplicando técnicas de depuração e raciocínio analítico.

---

## 🛠️️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica e acessível.
- **CSS3:** Estilização responsiva, Flexbox/Grid Layout e variáveis CSS.
- **JavaScript:** Interatividade de tela e manipulação do DOM.
- **Git & GitHub:** Controle de versão e hospedagem do código.

---

## 🚀 Desafios Enfrentados e Soluções (Troubleshooting)

Durante o desenvolvimento, surgiram divergências no código que exigiram investigação e correção manual para garantir o funcionamento correto da interface:

1. **Ajuste de Layout Responsivo:**
   - **Problema:** Desalinhamento de elementos e quebra de layout em telas menores.
   - **Solução:** Refatoração de regras de media queries e ajuste nas propriedades de Flexbox/Grid para garantir adaptação fluida.

2. **Ajustes de Sintaxe e Comportamento em JavaScript:**
   - **Problema:** Comportamentos inesperados em scripts de interatividade e escopo de eventos.
   - **Solução:** Uso do console do navegador (DevTools) para isolar erros de sintaxe e lógica, corrigindo a manipulação dos elementos no DOM.
